# Modern glibc support and verified release downloads

A fresh checkout can deploy to supported rooted LG TVs without a compiler. `deploy.sh` selects the legacy or modern injection path using the TV's glibc version. On newer firmware it downloads `magic-pointer-modern-arm.tar.gz` from this release and verifies the runtime files against the SHA-256 hashes committed with this tag.

The modern path uses unmodified ezinject source at `d9338952cd01597c5fdd7d6e98991474df5dc89c`, built with its public glibc loader API, plus a matching CRT bridge for the older PHP library. The PHP library and hook factory are fetched separately from the pinned `lginputhook` v1.4.0 source.

Tested successfully on LG OLED G4 (`OLED65G49LS.DEUQL.JP`), firmware `43.21.73`, webOS 26 / SDK `11.2.0-3703`, Linux `6.12.44-352` ARM64, with a 32-bit ARM `lginput2` and glibc `2.39`. Pointer suppression and buttons were confirmed on the TV; injection and repeated deployment preserved the service PID. Reboot behavior is not yet verified.

Also included: root/architecture preflight checks, `--check` without TV writes, atomic file replacement, hook-readiness checks, disposable ARM/Thumb integration tests, and automated deployment tests.

Thanks to [bciuca's original project](https://github.com/bciuca/disable-lg-magic-remote) for the idea and foundation, and to the ezinject, lginputhook, Frida, and webOS Homebrew projects. Component notices and the ezinject Zlib license are included in the archive.

Requires root SSH and a supported 32-bit ARM soft-float `lginput2`; this is not a universal firmware compatibility guarantee. See the README for installation and recovery instructions.
